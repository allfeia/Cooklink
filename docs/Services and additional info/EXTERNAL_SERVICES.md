## Интеграция с внешними сервисами (внутренняя логика)


| Сервис                    | Назначение                                       |
|---------------------------|--------------------------------------------------|
| **YouTube Data API**      | Получение метаданных видео, проверка доступности |
| **YouTube TimedText**     | Извлечение субтитров (CC)                        |
| **Yandex SpeechKit**      | Транскрибация аудио (fallback)                   |
| **Qwen-72B API**          | Извлечение рецепта из текста                     |
| **Yandex Object Storage** | Хранение PDF                                     |
