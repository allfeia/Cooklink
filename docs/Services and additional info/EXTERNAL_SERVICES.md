## Интеграция с внешними сервисами (внутренняя логика)


| Сервис                                   | Назначение                                                                                                                                                                                                          |
|------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Groq API** (`llama-3.3-70b-versatile`) | Извлечение рецепта из текста                                                                                                                                                                                        |
| **Gotenberg**                            | Генерация PDF из HTML-шаблона рецепта. Open-source, self-hosted (Docker), бесплатный, без лимитов. Поднимается через `docker-compose.yml` в корне репо, порт `3000`. Backend обращается по `GOTENBERG_URL` (`.env`) |
