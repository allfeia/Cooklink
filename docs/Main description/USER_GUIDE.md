# Руководство пользователя - ГОТОВЬ.ai / CookLink.ai

## 🎯 Быстрый старт

### Как использовать ГОТОВЬ.ai

1. **Откройте приложение**
   - Главная страница откроется с полем для ввода YouTube URL

2. **Вставьте ссылку на видео-рецепт**
   - Скопируйте ссылку на YouTube видео с рецептом
   - Вставьте её в поле ввода
   - Ссылка автоматически валидируется

3. **Нажмите "Сгенерировать рецепт"**
   - Дождитесь обработки (обычно 10-40 секунд)
   - Следите за прогрессом в процентах

4. **Изучите рецепт**
   - AI-сгенерированное изображение блюда
   - Время приготовления, сложность, количество порций
   - Список ингредиентов с точными пропорциями
   - Пошаговая инструкция приготовления
   - Полезные комментарии и советы
   - Ссылка на оригинальное видео

5. **Скачайте PDF**
   - Нажмите кнопку "Скачать PDF"
   - PDF будет сохранен на ваше устройство

## ⚙️ Настройки

### Смена темы
- **Светлая тема**: Классический белый фон, идеален для дневного использования
- **Темная тема**: Темный фон, комфортен для глаз в вечернее время
- **Переключение**: Кнопка с иконкой солнца/луны в правом верхнем углу

### Смена языка
- **Русский (RU)**: ГОТОВЬ.ai - полный интерфейс на русском языке
- **English (EN)**: CookLink.ai - complete English interface
- **Переключение**: Кнопка "RU/EN" в правом верхнем углу

## 💡 Советы

### Для лучших результатов:
1. Используйте видео с четким списком ингредиентов
2. Выбирайте видео с понятными шагами приготовления
3. Видео на русском или английском языке работают лучше всего

### Быстрые примеры:
На главной странице есть кнопки с готовыми примерами:
- Паста Карбонара
- Классический Борщ
- Торт Наполеон

Нажмите на любой пример для быстрой демонстрации

## 🔍 FAQ

**Q: Поддерживаются ли ссылки с других платформ?**
A: В текущей версии поддерживаются только YouTube ссылки.

**Q: Сохраняются ли мои рецепты автоматически?**
A: В текущей версии автоматическое сохранение не реализовано. Используйте кнопку "Скачать PDF" для сохранения рецепта.

**Q: Могу ли я редактировать рецепт?**
A: В текущей версии редактирование не поддерживается. Эта функция будет добавлена в следующих обновлениях.

**Q: Как поделиться рецептом?**
A: Используйте кнопку "Поделиться" в верхнем правом углу карточки рецепта.
