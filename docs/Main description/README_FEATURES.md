# CookLink.ai / ГОТОВЬ.ai

B2B веб-решение для конвертации видео-рецептов YouTube в структурированные PDF-рецепты.

## 🎨 Новые возможности

### ✅ Темная тема
- Переключение между светлой и темной темами через кнопку в шапке
- Автоматическое сохранение выбранной темы в localStorage
- Адаптированная цветовая палитра для обеих тем
- Акцентный цвет: #2563EB (Royal Blue) для светлой темы, #3b82f6 для темной

### 🌍 Мультиязычность
- Поддержка русского и английского языков
- Переключение языка через кнопку в шапке (RU/EN)
- Автоматическое сохранение выбранного языка
- Брендинг:
  - Русский: **ГОТОВЬ.ai**
  - English: **CookLink.ai**

### 🎨 Обновленный дизайн

#### Логотип
Уникальный логотип с комбинацией Play button (▶) и Chef hat (👨‍🍳)

#### Слоганы
- Русский: "Перестань перематывать. Начни готовить."
- English: "Stop rewinding. Start cooking."

#### Описание
- Русский: "Вставь ссылку на YouTube, получи красивый рецепт"
- English: "Paste a YouTube link, get a beautiful recipe"

### 🖼️ AI-генерация изображений блюд
- Автоматическая генерация изображения блюда на основе названия рецепта
- Использование Unsplash API для получения качественных фотографий еды
- Изображение отображается вверху карточки рецепта

### 🔗 Ссылка на исходное видео
- На странице рецепта внизу добавлена ссылка на оригинальное YouTube видео
- Кнопка "Смотреть на YouTube" / "Watch on YouTube"
- Открывается в новой вкладке

## 🛠️ Технический стек

- **React 18** с TypeScript
- **Tailwind CSS v4** для стилизации
- **Motion** для анимаций
- **jsPDF** для генерации PDF
- **Context API** для управления темой и языком
- **localStorage** для сохранения настроек

## 🎯 Дизайн-система

### Цвета
- **Primary**: #2563EB (Royal Blue)
- **Background Light**: #FFFFFF
- **Background Dark**: oklch(0.145 0 0)
- **Foreground Light**: oklch(0.145 0 0)
- **Foreground Dark**: oklch(0.985 0 0)

### Типографика
- **Шрифт**: Inter (system font)
- **Веса**: 400 (normal), 500 (medium), 700 (bold)

### Accessibility
- Контраст текста: минимум 4.5:1
- Focus states на всех интерактивных элементах
- Aria-labels для кнопок и инпутов
- Поддержка клавиатурной навигации

## 🚀 Использование

### Переключение темы
Нажмите на иконку солнца/луны в правом верхнем углу

### Переключение языка
Нажмите на кнопку "RU" или "EN" в правом верхнем углу

### Генерация рецепта
1. Вставьте YouTube URL в поле ввода
2. Нажмите "Сгенерировать рецепт"
3. Дождитесь обработки (10-40 секунд)
4. Просмотрите рецепт с AI-изображением блюда
5. Скачайте PDF или поделитесь рецептом
